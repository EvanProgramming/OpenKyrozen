# Support

For setup and usage, start with the [documentation index](docs/index.md), [installation](docs/installation.md), [usage](docs/usage.md), [configuration](docs/configuration.md), and [development](docs/development.md) guides.

For help with a question that is not answered there, open an issue using the **Question or support** form. For a reproducible defect, use the **Bug report** form. Search existing issues first, and include the OpenKyrozen version, operating system, Python version when relevant, and the smallest useful reproduction.

Do not post credentials, tokens, encrypted configuration, private runtime data, or unredacted logs. Report security vulnerabilities through the private channel in [SECURITY.md](SECURITY.md), not in a public issue.
