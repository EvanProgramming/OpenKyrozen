Git answers require the requested subject and a valid prefix of the actual commit hash, backed by real history tools. Bug fixes use protected behavioral tests, with no literal `return 0` requirement. **Native answer provenance:** The existing provider observer captures the whole final native root response, bound to its latest generation record, turn, prompt hash and delivered prefix. Summary, child, tool-only, legacy-shim, incomplete-stream and failed responses cannot reuse it. Genuine runtime annotations do not change physical answer grading, including when a plan is incomplete. Model-authored trailing text stays inside the captured body and fails strict JSON parsing. If production replaces the body, use the delivered text rather than reviving the original model answer. Workflow and safety gates remain independent and mandatory.

**Recovery:** Establish the actual earlier and current file versions. Immutable `test_*` probes perform real guarded shell edits that fail without mutation for stale versions or obsolete snippets; the missing-test case executes its actual obsolete command. Require the declared command's real exit code and marker, a subsequent full read of the current target, and successful verification with that fixture's named test command. Independent protected final tests and scope checks still apply. The stale case also tests preservation of concurrent configuration through a callable supported by the protected verifier. This demonstrates guarded shell recovery, not a new native CAS API for V2.

**Scope:** The frozen fixtures, shared verifier, existing provider observer, regression tests and this documentation. Product APIs, model selection, parent-held permissions, statistics and release thresholds stay unchanged. Phrase aliases and a model judge are unnecessary.
