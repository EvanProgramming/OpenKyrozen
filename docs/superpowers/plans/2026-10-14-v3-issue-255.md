## Goal and boundaries

Establish one immutable runtime-owned event envelope and publisher, then adapt existing event callbacks and CLI/TUI/Web/SSE wire shapes at the interface edges. Preserve durable ownership of task, interaction, usage, and receipt state. Observers remain failure-isolated and cannot authorize work. Keep AgentEngine migration, database redesign, and provider continuation payloads out of scope.

The current compatibility path has a dictionary callback in `openkyrozen/learning/failures.py`, a `ContextVar` callback in `openkyrozen/app/state.py`, text events emitted throughout agent modules, and separate filtering/rendering logic in CLI/TUI/Web. Provider stream events already originate as typed provider records. The change will bridge these existing paths through the canonical publisher instead of adding another event store.

**Files:**

## Compatibility and risks

Existing `on_event` consumers retain dictionaries through a compatibility adapter. CLI/TUI/Web/SSE wire fields remain compatible while sourcing them from canonical events. Text protocol filtering remains available only at the legacy boundary; native response text is not inspected for control syntax. Event payloads are JSON-safe, bounded/redacted projections. Durable stores and usage ledgers remain the sources of truth. Cancellation and observer failures must not alter execution outcomes.
